# Expressive Widgets

Material Expressive home-screen widgets for Android, configurable from inside the app.

**Widgets:** Batteries (phone + Bluetooth earphones). More to come (music, weather, savings).

## Install & updates

Add this repo in [Obtainium](https://github.com/ImranR98/Obtainium) and enable *Include prereleases*.
Every change to `main` publishes a new `x.y.z-beta.N` prerelease; stable versions are tagged `x.y.z`.

## Adding a widget

See `widgets/WidgetKind.kt` for the steps.
- Noto Emoji font (OFL) is bundled for the monochrome emoji style.
